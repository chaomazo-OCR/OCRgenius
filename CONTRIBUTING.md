# Contributing to OCRgenius

Contributions are welcome across the landing experience, accessibility, document workflows, integrations, and developer tooling.

## Development workflow

1. Fork and clone the repository.
2. Install dependencies with pnpm install.
3. Create a focused branch.
4. Make a small coherent change and add tests when relevant.
5. Run pnpm run typecheck and pnpm run build.
6. Open a pull request against main with the user impact clearly described.

## Guidelines

- Keep the interface grounded in freight operations and document intelligence.
- Prefer semantic HTML, keyboard-friendly controls, and visible focus states.
- Do not add credentials, customer documents, or private data to commits.
- Distinguish extracted values from validated values and make uncertainty clear.
- Update the README when the workspace workflow changes.

For larger changes, open an issue first so the design can be discussed before implementation.
